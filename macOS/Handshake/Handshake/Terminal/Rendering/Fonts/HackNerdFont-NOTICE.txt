Hack Nerd Font bundled privately with Handshake

Nerd Fonts version: 3.4.0
Hack version: 3.003
Source: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/Hack.zip

The four standard HackNerdFont faces (not Mono or Propo) are redistributed
with metadata-only name changes so Handshake's private fallback does not shadow
fonts installed by the user. The private family is "Handshake Terminal Nerd Font";
PostScript names are HandshakeHackNF-Regular, -Bold, -Italic, and -BoldItalic.
Glyph outlines, advances, hinting, kerning, character maps, and style flags
are unchanged. Only the naming table and checksum adjustment were modified.

Name-table transformation (initial private font: FontTools 4.60.1;
Handshake metadata rename: Python standard library):
- Read upstream faces with TTFont(recalcBBoxes=False, recalcTimestamp=False).
- Change existing records 1, 16, 21 to "Handshake Terminal Nerd Font".
- Change record 3 to "3.003;HNDS;HandshakeHackNF-<style>".
- Change records 4 and 18 to the private family plus the existing subfamily.
- Change record 6 to "HandshakeHackNF-<style>" and record 25 to "HandshakeHackNF".
- Preserve all other records, including subfamilies, copyright, and licenses.
- Save the initial private font with reorderTables=False. For the Handshake
  rename, replace Twine with Handshake and TWNE with HNDS in the name records,
  rebuild the name table and checksums, and preserve all other table bytes.
  Verify every table except name/head is byte-identical and head differs only
  at its checksum-adjustment bytes.
