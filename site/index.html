A folder, its sessions, and the agents working in them.

Open a folder and organize the work into sessions. Each session holds workflows, and in a workflow your agents implement, review, and coordinate through explicit handoffs. Terminals, files, and traces stay in one window.

how workflows work ↗

bring your own harness

implementer▸Codex
coordinator▸OMP
reviewer▸Claude Code

A role doesn't depend on the tool that fills it. Mix Codex, Claude Code, pi, Antigravity, OMP, OpenCode, and Kiro CLI across roles, or start with a plain shell. Install and sign in to each tool separately.

browser use

Open the web beside your terminals, and let agents drive it while you watch.

  • Browser tabs. Press ⌥⌘T or the globe button to open a page next to your work. Tabs belong to their session and come back after relaunch.
  • Agent browser control beta An agent opens its own tabs, reads the page, and clicks, types, scrolls, and takes screenshots. Turn it on in Settings → Experimental.
  • You stay in charge. The browser shows which terminal is driving it, and Stop / Take over hands the page back to you. Passwords, dialogs, and uploads stay with you.
  • Works with your harness. Codex and Claude Code get a browser tool for the session. Other agents use the bundled command-line tool.
# the agent opens a tab it owns $ "$HANDSHAKE_CLI" browser open http://localhost:4173 # reads the page, then acts on its elements $ "$HANDSHAKE_CLI" browser --tab ID snapshot $ "$HANDSHAKE_CLI" browser --tab ID fill e3 "Clear deadfall" $ "$HANDSHAKE_CLI" browser --tab ID click e7 $ "$HANDSHAKE_CLI" browser --tab ID screenshot

keep the thread

A window for each folder

Sessions and workflows live with the folder. Each folder keeps its own terminals, files, and tabs.

Follow the handoffs

See workflow activity in Traces, inspect what happened, and jump to recorded terminal output.

Pick up where you left off

Restore sessions, pane layouts, and retained output. Resume agent conversations when the harness supports it.

Stay close to your files

Browse the folder and make small text edits, with undo and checks for changes made on disk.

Give it
a spin.

  1. Install. Run the Homebrew command, or download the app and drag Handshake to Applications.
  2. Open a folder. Create a session, choose a workflow type, and pick the agent tools you've installed.
  3. Start with a task. Type it into the first agent's terminal and follow the handoffs.
