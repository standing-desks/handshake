Interface changes · inspection findings

Keep the decision visible. Tuck the paths away.

What the user sees

  1. Import beside the Memories header.
  2. Claude Code → Codex, with the project name.
  3. A clear state and count of native memory files.
  4. Import to Codex, plus Refresh and Done.

“Memory locations” expands only when the user wants to inspect native paths. The sheet uses its content’s height instead of reserving a large empty area.

Why the controls changed

A visible Import label makes the action discoverable. The direction prevents a mistaken expectation of two-way synchronization. Status comes before file paths, so the next action is clear.

Busy and unavailable states disable the primary action. When source files have all been removed but imported copies remain, the action is explicitly Remove imported memories.

These are design improvements identified by inspection, not claims that user research measured a benefit.
